# 表單範本

機關實務上會用到的巡檢表、申請單與紀錄表，共 **22 份 Word（.docx）檔案**，
可直接下載列印或複製後修改。每份表單最後一行都標註了對應的手冊章節，
想知道「這一欄為什麼要填」就回去看那一章。

## 如何修改與重新產生

表單內容寫在 `_工具/表單定義.py`，用 Python 標準函式庫直接組出 Office Open XML，
**不需要安裝 python-docx 或任何第三方套件**。

```bash
python3 _工具/產生表單.py --list          # 列出所有表單
python3 _工具/產生表單.py                 # 全部重新產生
python3 _工具/產生表單.py 機房巡檢表       # 只產生指定的一份
```

要新增表單就在 `_工具/表單定義.py` 加一個 dict 並掛進 `FORMS`，
區塊型別有 `H`（標題）、`P`（段落）、`T`（表格）、`F`（兩欄填寫區）四種，
另有 `checklist()` 可以把「檢查項目／檢查方式」清單直接轉成勾選表格。

> [!warning] 未實機驗證
> 產出的 .docx 已通過 ZIP 結構與 XML 格式檢查，但本環境沒有 Microsoft Word，
> 尚未在 Word 或 LibreOffice 實際開啟確認排版。首次使用請先開一份確認版面。
