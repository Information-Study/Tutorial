```yaml
category: Linux基礎
difficulty: 入門             # 入門 / 進階 / 專家

prerequisites: ["[[020-01-05-cmd-Linux-路徑導覽與檔案操作]]"]

```

### 每個章節的收尾文件（保留編號 98 / 99）

每一個最末端章節資料夾，除了教學文之外固定再放兩份：

| 編號 | 類型 | 文件 | 內容 |
| ---: | --- | --- | --- |
| **98** | `trouble` | 常見故障排除手冊 | 依「症狀」查的索引，每個情境連回原文說明原理，含一頁式急救卡 |
| **99** | `exam` | 總結小考 | 是非 50 題 + 選擇 50 題，詳解 3~8 行並以 `→ 詳見 [[檔名]]` 指回原文 |

例：`020-02-01-98-trouble-SSH-常見故障排除.md`、`020-02-01-99-exam-SSH-總結小考.md`

### 章節骨架（固定 13 段）

這篇你會學到 → 前置知識 → 觀念說明 → 安裝或基礎操作 → 進階應用 → 完整實戰範例
→ 常見錯誤與排錯 → 安全性注意事項 → 速查表 → 練習題 → **小測驗** → 延伸閱讀

**小測驗**每篇必備，最多 10 題，答案集中在一個預設摺疊的
`> [!question]- 測驗答案` callout 內，每題附成因說明並指回篇內對應段落。

### 星號重要度

全篇用 ★ 標記重要程度，讓維運人員掃讀時能立刻分辨輕重：

| 星級 | 意義 |
| --- | --- |
| `★` | 一般提示 |
| `★★` | 值得注意 |
| `★★★` | 重要、容易出錯 |
| `★★★★` | 關鍵，出錯會造成服務中斷或資安事件 |
| `★★★★★` | 最高等級（資料外洩、不可逆損毀） |

### 其他

- 交叉引用一律用 `[[檔名]]`，不要用相對路徑。
- **檔名格式**（2026-08-29 改制完成）：

  ```
  三層目錄： <群組3碼>-<章2碼>-<序2碼>-<類型>-<主題前綴>-<標題>.md
  四層目錄： <群組3碼>-<章2碼>-<子章2碼>-<序2碼>-<類型>-<主題前綴>-<標題>.md
  ```

  例：`010-02-03-guide-網概-網路分層模型.md`、`060-04-01-05-svc-MySQL-備份與還原.md`。
  類型為 `cmd`／`svc`／`guide`／`ref`／`idx`／`trouble`／`exam`；
  索引頁序號固定 `00`、故障排除固定 `98`、總結小考固定 `99`（98/99 為保留號）。
  編號依**建議學習順序＋邏輯順序**排定，字典序即閱讀序。**全 vault 檔名唯一**。
  新增篇章請用 `_工具/新增筆記.py` 產生，不要手動命名。
- 程式碼區塊一定標語言：`bash` `powershell` `nginx` `yaml` `ini` `sql` `php` `json` `dockerfile` `cisco`。
- 長設定檔放 `_設定檔範例/`，內文只放關鍵片段並連結過去。
- 未在實機驗證過的內容加 `> [!warning] 未實機驗證`。

## 維護工具

```bash
python3 _工具/健檢.py              # ★ 一次跑完所有結構檢查（提交前建議跑）
python3 _工具/健檢.py --quiet      # 只顯示問題
python3 _工具/重建索引.py          # 新增／改名／搬移筆記後，重建所有索引表格
python3 _工具/重建索引.py --check  # 只檢查不寫入（適合 pre-commit / CI）
python3 _工具/檢查連結.py          # 檢查斷掉的 wikilink，必須為 0
python3 _工具/進度統計.py          # 各章撰寫進度
python3 _工具/新增筆記.py <資料夾> <標題> --kind {cmd|svc|guide|ref} [選項]
```

`健檢.py` 會一次檢查：檔名唯一性、章節編號連續性、frontmatter 完整性、
索引頁覆蓋、已完成篇章的必備段落、群組標籤一致性與撰寫進度。有問題時離開碼為 1。

索引頁的「本章導覽」與「建議閱讀順序」是手寫的，重建時會保留；
只有「子分類」與「篇章列表」兩張表會依 frontmatter 重新產生。

### 新增一篇教學

```bash
python3 _工具/新增筆記.py "060-軟體與開發工具/02-Web伺服器/02-Nginx" "Nginx限流與防爆量" \
    --kind svc --difficulty 進階 \
    --desc "用 limit_req 與 limit_conn 擋住暴衝流量" \
    --tags "服務/nginx,主題/效能" \
    --prefix Nginx \
    --prereq "060-02-02-08-svc-Nginx-效能調校" --related "060-02-02-09-svc-Nginx-安全設定"
python3 _工具/重建索引.py
```

`--kind` 決定章節骨架：`cmd`（指令教學）、`svc`（服務教學）、`guide`（觀念與實戰）、`ref`（速查頁）。

### 新增一個章節

1. 在群組資料夾下建 `NN-章節名/`
2. 從 `_範本/索引MOC範本.md` 複製出 `<群組>-<章>-00-idx-<主題前綴>-<章節名>.md`，
   填好 `desc` 與「本章導覽」「建議閱讀順序」
3. 用 `新增筆記.py` 加入教學文
4. 跑 `重建索引.py`，父層索引會自動出現這個子分類

## 工作流程

任何改動 vault 內容後，依序執行：

```bash
python3 _工具/重建索引.py
python3 _工具/檢查連結.py
python3 _工具/健檢.py
git add -A && git commit -m "docs(<章節>): <做了什麼>"
git push origin main
```

**每完成一個章節（或一批筆記）commit 後必須 `git push`。**
認證走 gh CLI（`gh auth login` 後 `gh auth setup-git`）。

### 提交規範

```
docs(nginx): 新增反向代理與負載平衡教學
docs(juniper): 補充 VLAN Trunk 設定範例
chore: 章節重編號搬遷
fix(連結): 修正 Laravel 部署章節的斷掉連結
```
